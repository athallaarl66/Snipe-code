# US-003: Dry-Run Preview — Production Requirements

> Status: the folder structure below is generated by the current presets. Page
> content, SEO tags, dark mode, and responsive layout are design plans, not generated
> output. See `docs/features/technical.md` section 3 for what a preset actually writes.

## User Acceptance
**As a** developer
**I want** lihat struktur yang bakal digenerate sebelum bikin file
**So that** saya yakin sebelum eksekusi

## Business Value
Mencegah mistake — user bisa review dulu sebelum file beneran dibuat.

## User Persona
Developer yang hati-hati, mau pastikan output sebelum commit.

## User Journey
1. Run `snipe-code new --dry-run`
2. Pilih template + stack seperti biasa
3. Lihat folder tree output
4. Tidak ada file yang dibuat

## Success Criteria
- [x] Output folder tree jelas
- [x] Tidak ada file/folder yang terbuat
- [x] Tidak ada prompt yang menggantung saat stdin bukan terminal
