# US-005: Template Company Profile — Production Requirements

## User Acceptance
**As a** freelancer
**I want** template company profile yang siap di-custom
**So that** saya bisa deliver ke klien dalam hitungan jam

## Business Value
Freelancer bisa deliver company profile website dalam hitungan jam bukan hari.

## User Persona
Freelancer yang sering bikin website company profile untuk klien UKM/startup.

## User Journey
1. Pilih "Company Profile"
2. Pilih stack (default: Next.js, no backend)
3. Structure dengan halaman: Home, About, Services, Contact, Team
4. SEO meta tags sudah included

## Success Criteria
- [ ] Struktur halaman lengkap: Home, About, Services, Contact, Team
- [ ] SEO meta tags di semua halaman
- [ ] Responsive layout
- [ ] Backend opsional
