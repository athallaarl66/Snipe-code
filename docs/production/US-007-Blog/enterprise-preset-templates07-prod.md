# US-007: Template Blog/Posts — Production Requirements

> Status: the folder structure below is generated by the current presets. Page
> content, SEO tags, dark mode, and responsive layout are design plans, not generated
> output. See `docs/features/technical.md` section 3 for what a preset actually writes.

## User Acceptance
**As a** content creator
**I want** template blog dengan CMS-ready structure
**So that** saya bisa nulis dan publish tanpa setup dari nol

## Business Value
Content creator bisa langsung nulis konten tanpa pusing soal struktur blog.

## User Persona
Blogger, content creator, atau developer yang mau punya tech blog pribadi.

## User Journey
1. Pilih "Blog / Posts"
2. Pilih stack (default: Next.js, optional backend)
3. Structure: posts/, categories/, tags/, author page
4. Markdown/MDX support: satu contoh `frontend/src/posts/hello-world.mdx`
5. RSS: hanya sampel statis `frontend/public/rss.xml` dengan URL localhost, tidak
   ikut berubah saat post ditambah

## Success Criteria
- [x] Struktur: posts/, categories/, tags/, author page
- [x] Markdown/MDX support
- [ ] RSS feed auto-generated (belum; yang ada sampel statis)
- [x] Backend opsional
