# US-007: Template Blog/Posts — Production Requirements

## User Acceptance
**As a** content creator
**I want** template blog dengan CMS-ready structure
**So that** saya bisa nulis dan publish tanpa setup dari nol

## Business Value
Content creator bisa langsung nulis konten tanpa pusing soal struktur blog.

## User Persona
Blogger, content creator, atau developer yang mau punya tech blog pribadi.

## User Journey
1. Pilih "Blog / Posts"
2. Pilih stack (default: Next.js, optional backend)
3. Structure: posts/, categories/, tags/, author page
4. Markdown/MDX support
5. RSS feed auto-generated

## Success Criteria
- [ ] Struktur: posts/, categories/, tags/, author
- [ ] Markdown/MDX support
- [ ] RSS feed auto-generated
- [ ] Backend opsional
