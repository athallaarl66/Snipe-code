# US-001: Init dengan Template — Production Requirements

> Status: the folder structure below is generated by the current presets. Page
> content, SEO tags, dark mode, and responsive layout are design plans, not generated
> output. See `docs/features/technical.md` section 3 for what a preset actually writes.

## User Acceptance
**As a** developer
**I want** memilih template preset saat `snipe-code new`
**So that** saya langsung dapat struktur proyek yang sesuai kebutuhan

## Business Value
Developer bisa langsung mulai develop tanpa setup manual. Mengurangi waktu inisialisasi dari jam ke < 30 detik.

## User Persona
Developer yang ingin cepat start proyek baru dengan struktur yang sudah benar.

## User Journey
1. Run `snipe-code new`
2. Lihat daftar template: No Template, Company Profile, Portfolio, Blog
3. Pilih salah satu
4. Pilih stack (Frontend + Backend + DB)
5. Masukkan nama project
6. Template di-generate

## Success Criteria
- [x] Template bisa dipilih via arrow key
- [x] Struktur folder sesuai template ter-generate
- [x] Security config dasar otomatis included (`.env.example`, `.gitignore`)
- [x] Preset company-profile menggenerate 7 folder, portfolio 6, blog 6

## Edge Cases
- User pilih "No Template" → skip ke stack selection langsung
- Target folder sudah ada → prompt Overwrite atau Cancel; tanpa terminal berhenti
  dengan `Error: Folder "<path>" already exists`
- User cancel di tengah → tidak ada perubahan di filesystem
