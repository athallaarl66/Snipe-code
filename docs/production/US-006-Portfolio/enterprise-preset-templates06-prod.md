# US-006: Template Portfolio — Production Requirements

## User Acceptance
**As a** developer/designer
**I want** template portfolio untuk showcase project
**So that** saya punya landing page personal yang profesional

## Business Value
Developer/designer punya portfolio online yang profesional dalam hitungan menit.

## User Persona
Developer atau designer yang butuh personal branding website.

## User Journey
1. Pilih "Portfolio"
2. Pilih stack (default: Next.js/Vue, no backend)
3. Structure dengan Hero, Projects grid, Skills, Experience, Contact
4. Dark/light mode included
5. Deploy-ready ke Vercel/Netlify

## Success Criteria
- [ ] Halaman: Hero, Projects grid, Skills, Experience, Contact
- [ ] Dark/light mode toggle
- [ ] Projects data dari JSON/YAML
- [ ] Deploy-ready
