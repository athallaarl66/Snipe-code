# US-006: Template Portfolio — Production Requirements

> Status: the folder structure below is generated by the current presets. Page
> content, SEO tags, dark mode, and responsive layout are design plans, not generated
> output. See `docs/features/technical.md` section 3 for what a preset actually writes.

## User Acceptance
**As a** developer/designer
**I want** template portfolio untuk showcase project
**So that** saya punya landing page personal yang profesional

## Business Value
Developer/designer punya portfolio online yang profesional dalam hitungan menit.

## User Persona
Developer atau designer yang butuh personal branding website.

## User Journey
1. Pilih "Portfolio"
2. Pilih stack (default: Next.js/Vue, no backend)
3. Folder Hero, Projects grid, Skills, Experience, Contact dibuat, plus `projects.json`
4. Dark/light mode belum digenerate (rencana)
5. Deploy ke Vercel/Netlify butuh setup user (rencana)

## Success Criteria
- [x] Folder: Hero, Projects grid, Skills, Experience, Contact
- [ ] Dark/light mode toggle (rencana)
- [x] Projects data dari JSON
- [ ] Deploy-ready (butuh setup user)
