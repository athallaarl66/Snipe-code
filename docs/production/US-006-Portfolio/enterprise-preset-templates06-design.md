# US-006: Template Portfolio — Design Specifications

> Status: the folder structure below is generated by the current presets. Page
> content, SEO tags, dark mode, and responsive layout are design plans, not generated
> output. See `docs/features/technical.md` section 3 for what a preset actually writes.

## Page Structure
```
frontend/src/
├── pages/
├── components/
│   ├── sections/
│   │   ├── hero/
│   │   ├── projects-grid/
│   │   ├── skills/
│   │   ├── experience/
│   │   └── contact/
│   ├── ui/
│   └── layout/
├── data/
│   └── projects.json
```

## Visual Treatment
- Hero: full-screen with name + tagline + CTA
- Projects: grid layout with image + title + description
- Skills: progress bars or tag chips
- Experience: timeline layout
- Contact: simple form + social links

## Dark/Light mode (plan)
- Toggle button in header
- Default: system preference
- Persisted in localStorage

Nothing of this ships: the preset writes folders and
`frontend/src/data/projects.json` only.

## Responsive
- Desktop: full grid
- Tablet: 2-column grid
- Mobile: single column, stacked sections
