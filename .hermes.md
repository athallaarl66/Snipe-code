# XERJ for SNIPE-CODE

Use XERJ MCP `xerj_search` / `xerj_def` before non-trivial changes in unfamiliar code. Cite returned `path:line`; treat results as indexed snapshots and verify current source before editing.

This repository is indexed on the local XERJ node under prefix `snipe-code`. For CLI fallback, run `xerj search --prefix snipe-code "<query>"` or `xerj def --prefix snipe-code <symbol>` from this repository.
